# ToDoList App

This iOS app built with Swift and UIKit. ToDoList allows you to create tasks for your day and categorize them.
The app supports light and dark mode.

## Documentation

ToDo app's documentation can be found in Xcode. To view documentation, clone the project, navigate to the toolbar where you will find the option Window and 
select Developer Documentation
